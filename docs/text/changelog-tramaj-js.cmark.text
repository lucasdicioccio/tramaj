# Changelog: tramaj-js

Release history of `tramaj-js`, the TypeScript implementation for Node.js and browsers. Releases happen when there are major changes rather than on a schedule; each entry below is one version. Every implementation has its own page like this one, and each page is tagged so the site builds one Atom feed per implementation: #changelog #javascript #tramaj-js

The 0.2.0 entry has breaking changes to numbers: [Migrating to integers and floats](/migrating-to-integers-and-floats.html ) says what to do about each.
