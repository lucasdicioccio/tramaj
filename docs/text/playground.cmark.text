This is the same playground built from the [tramaj](https://github.com/lucasdicioccio/tramaj ) repository's PureScript sources, published here as a static bundle so it can be tried without a local build. It parses and evaluates tramaj templates in the browser — nothing is sent to a server. Tabs act as importable libraries for each other; toggle "Symbolic mode" to see the v3 envelope instead of a finished document. The arithmetic builtins are turned on: the _arithmetic-demo_ tab shows them over integers and floats.

![Editor tabs and a context are parsed and evaluated in the browser; Symbolic mode decides between a finished document and the v3 envelope](/gen/images/playground-flow.dot.png )

See [Getting started](/howto-humans.html ) for running the same language from the command line, or [Use cases](/use-cases.html ) for where it fits.

```html
<iframe class="playground-frame" src="/tramaj-playground.html" title="tramaj playground"></iframe>
```

If the embedded frame does not load, open the [playground](/tramaj-playground.html ) directly.
