Changelog: tramaj-cli-rs

Release history of tramaj-cli-rs, the standalone Rust command-line interface over tramaj-rs. Releases happen when there are major changes rather than on a schedule; each entry below is one version. Every implementation has its own page like this one, and each page is tagged so the site builds one Atom feed per implementation: #changelog #rust #tramaj-cli-rs

tramaj-cli-rs 0.1.0unreleased

Rust port of tramaj-cli's Main.purs over the tramaj-rs crate.

  • added Template + JSON context evaluation and the `analyze` subcommands, as a single static binary.
