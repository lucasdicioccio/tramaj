tramaj

A small template language for turning a JSON value into a document tree.

Templates are meant to be comfortable to write by hand and easy for an LLM to emit: a HAML-like block syntax for structure, a jq-flavoured expression language for the data half, and a deliberately tiny builtin set. Rendering is decoupled from the language — evaluation produces a generic Node AST, and it is the host that decides whether that becomes Halogen HTML, JSON, or anything else.

@items=$ctx.items
@n=cardinality($items)
.div(class: "items",
  .h1("Items"),
  .p("there are `$n` of them"),
  .ul(map($items, (i) => .li(action("on-click", "select", {"id": $i.id}), $i.name))))

Bindings are evaluated once, in order. `$n` interpolates into a string; a bare $path can be used directly as a child. action(...) attaches an opaque, structured action to an element — the language recognises the syntax but assigns it no meaning, leaving the host to map the key onto a real event handler.

Go straight to specs/reference.md on GitHub for the full spec, or explore the site below.
