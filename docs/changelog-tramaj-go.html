Changelog: tramaj-go

Release history of tramaj-go, the Go implementation, standard library only. Releases happen when there are major changes rather than on a schedule; each entry below is one version. Every implementation has its own page like this one, and each page is tagged so the site builds one Atom feed per implementation: #changelog #go #tramaj-go

tramaj-go 0.1.0unreleased

Go port: parser, evaluator (concrete and symbolic modes), Node JSON codec, static analyses and a tramaj-go CLI. Standard library only, Go 1.21+.

  • added Hand-written port checked against `corpus/cases` by `corpus_test.go`: every case passes in both modes.
