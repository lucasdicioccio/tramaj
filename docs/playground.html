This is the same playground built from the tramaj repository’s PureScript sources, published here as a static bundle so it can be tried without a local build. It parses and evaluates tramaj templates in the browser — nothing is sent to a server. Tabs act as importable libraries for each other; toggle “Symbolic mode” to see the v3 envelope instead of a finished document.

See Getting started for running the same language from the command line, or Use cases for where it fits.

If the embedded frame does not load, open the playground directly.
