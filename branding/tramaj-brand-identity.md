# Tramaj --- Brand Identity

> A small functional language for composing values and documents.

## 1. Brand idea

**Tramaj** is a language for weaving computation and document structure
together.

The name evokes the French **trame**: an underlying structure, weave,
pattern, or framework. The final **-aj** gives it a distinct identity
and a slightly technical, invented-language character.

The brand should communicate:

-   **Composition** --- small pieces become larger structures.
-   **Structure** --- documents have a real tree behind them.
-   **Flow** --- values move through expressions into documents.
-   **Lightness** --- the language is deliberately small.
-   **Independence** --- the core does not belong to HTML, a UI
    framework, or a particular host.
-   **Precision** --- a few carefully chosen constraints make important
    semantics inspectable.

Tramaj should feel like a **language**, not a framework, SaaS product,
or design system.

------------------------------------------------------------------------

## 2. Positioning

### One-line description

> **Tramaj is a small functional language for composing values and
> documents.**

### Short description

> Tramaj combines a small expression language with composable document
> construction. Programs evaluate to values or generic document trees,
> while hosts decide how those results are rendered or interpreted.

### Longer description

> Tramaj is a small, embeddable language for composing data and
> documents. It provides expressions, functions, reusable components,
> and a generic document tree without tying the language to HTML or a
> particular UI framework. Hosts provide capabilities such as builtins,
> imports, and rendering.

------------------------------------------------------------------------

## 3. Personality

Tramaj is:

-   **Quietly clever**
-   **Technical but approachable**
-   **Minimal**
-   **Compositional**
-   **Precise**
-   **Playful without being whimsical**

It is not:

-   Corporate
-   Futuristic
-   Cyberpunk
-   Enterprise-heavy
-   Cute
-   Overly French-themed
-   "AI-looking"

The identity should reward a second look rather than announce a metaphor
immediately.

------------------------------------------------------------------------

# 4. Logo

## Primary concept: the woven T

The logo is an abstract **T constructed from two interwoven strokes**.

One stroke establishes a horizontal structural line. Another travels
vertically through it. At their intersection, the strokes appear to pass
**over and under one another**.

The mark represents:

-   the **T** in Tramaj;
-   the **trame** / weave behind the name;
-   composition;
-   two layers becoming one structure;
-   values and documents crossing paths.

The weave should be subtle. It should read first as a clean geometric
mark and only then reveal the metaphor.

### Logo characteristics

-   Geometric
-   Compact
-   Recognizable at favicon size
-   Works in one color
-   No gradients required
-   No literal HTML brackets
-   No curly braces
-   No Eiffel Tower
-   No browser-window imagery

The logo should not look like a generic "developer tool" icon.

------------------------------------------------------------------------

## Logo lockups

### Horizontal

``` text
[ woven T ]  tramaj
```

The horizontal lockup is the default for websites, documentation,
GitHub, and presentations.

### Icon

``` text
[ woven T ]
```

Use for:

-   favicon
-   app/icon surfaces
-   package badges
-   avatars
-   small UI placements

### Wordmark

``` text
tramaj
```

Use the lowercase wordmark wherever the surrounding context already
establishes the product.

Lowercase reinforces the language's modest, tool-like character.

------------------------------------------------------------------------

# 5. Color

The initial visual direction uses a restrained two-tone palette.

## Tramaj Coral

**Primary accent**

-   HEX: `#F06A55`
-   RGB: `240, 106, 85`

Use for:

-   logo accent stroke
-   highlights
-   links where appropriate
-   selected states
-   small visual emphasis

Coral gives Tramaj warmth without making it look playful or
consumer-oriented.

## Tramaj Ink

**Primary dark**

-   HEX: `#172533`
-   RGB: `23, 37, 51`

Use for:

-   wordmark
-   primary text
-   dark logo variant
-   headings
-   code-adjacent surfaces

The blue-black ink balances the coral and gives the identity a technical
foundation.

## Paper

**Primary light**

-   HEX: `#FAF9F6`

Use as the preferred light background.

The identity should generally feel closer to **paper and ink** than to a
glossy software dashboard.

## White

-   HEX: `#FFFFFF`

Use where pure contrast is needed, especially for reversed marks.

------------------------------------------------------------------------

# 6. Color combinations

Preferred:

``` text
Paper + Ink
Paper + Coral + Ink
Ink + White
Coral + White
```

The logo's two-color version should normally use:

-   Ink for the structural stroke;
-   Coral for the crossing/weaving stroke.

A monochrome version must always remain valid.

Do not make the brand dependent on the coral/ink distinction for
recognition.

------------------------------------------------------------------------

# 7. Typography

The wordmark should use a **geometric humanist sans-serif** with:

-   rounded forms;
-   generous counters;
-   clean terminals;
-   moderate stroke contrast;
-   a distinctive lowercase `a`;
-   a distinctive lowercase `j`.

The typography should feel contemporary but not fashionable.

### Suggested character

Think:

> geometric + editorial + developer tool

rather than:

> startup + futuristic + monospace

The main brand typeface does **not** need to be monospace.

For code, documentation examples, and technical material, use a separate
monospace face.

------------------------------------------------------------------------

# 8. Graphic language

The visual system should borrow from the idea of a **trame** without
becoming literal textile branding.

Useful motifs:

-   crossing lines;
-   grids;
-   paths;
-   nested structures;
-   simple node/tree diagrams;
-   over/under intersections;
-   repeated structural units.

Avoid:

-   fabric textures;
-   thread photographs;
-   literal weaving illustrations;
-   excessive grids;
-   decorative patterns that compete with code.

A graphic should feel as though it could have been generated from a
small set of compositional rules.

------------------------------------------------------------------------

# 9. Motion

If motion is used, the logo's two strokes may be introduced as
independent paths that **weave together**.

A good animation:

1.  horizontal structure appears;
2.  vertical structure travels through it;
3.  intersection resolves into the final woven T;
4.  everything settles immediately.

Motion should be short and quiet.

Do not use:

-   spinning logos;
-   bouncing;
-   elastic animation;
-   particle effects;
-   terminal typing effects.

The brand should feel deliberate, not energetic.

------------------------------------------------------------------------

# 10. Voice

Tramaj's written voice is:

-   concise;
-   technical;
-   confident;
-   direct;
-   occasionally dry or playful;
-   never marketing-heavy.

Prefer:

> Compose values and documents.

over:

> Unlock a revolutionary new paradigm for next-generation document
> composition.

Prefer:

> The host decides how a document is rendered.

over:

> Tramaj seamlessly empowers developers to render content anywhere.

The language itself is the interesting thing. The brand does not need to
oversell it.

------------------------------------------------------------------------

# 11. Naming and capitalization

Preferred:

> **Tramaj**

In running text, lowercase is also acceptable when referring to the tool
in a code-oriented context:

> `tramaj`

Use **Tramaj** for:

-   prose;
-   headings;
-   brand presentation.

Use **`tramaj`** for:

-   package names;
-   repository names;
-   command names;
-   code;
-   identifiers.

Avoid:

-   TRAMAJ
-   Tramaj.js
-   Tramaj Lang
-   Tramaj Framework

unless a specific technical distinction requires it.

------------------------------------------------------------------------

# 12. Taglines

The brand does not require a permanent tagline.

If one is useful, preferred options are:

### Primary

> **Compose values. Build documents.**

### More conceptual

> **A language for structured composition.**

### More technical

> **Values in. Documents out.**

The first is the strongest general-purpose line.

------------------------------------------------------------------------

# 13. Logo usage

## Clear space

Maintain at least the height of the vertical stem of the T around the
logo on all sides.

Do not crowd the mark against text, borders, or UI controls.

## Minimum size

The icon should remain recognizable when reduced to approximately 16--20
px.

At very small sizes, simplify the weave rather than allowing the
crossing to collapse visually.

## Backgrounds

Preferred backgrounds:

-   Paper
-   White
-   Ink

Coral may be used as an icon background with a white mark.

------------------------------------------------------------------------

# 14. Incorrect usage

Do not:

-   stretch the logo;
-   rotate the logo;
-   add shadows to the primary mark;
-   use gradients in the core identity;
-   outline the wordmark;
-   replace the weave with literal brackets;
-   add code symbols to the icon;
-   place the logo inside a generic hexagon or shield;
-   decorate the logo with French/Paris landmarks;
-   use multiple accent colors.

The logo should remain **structural, not illustrative**.

------------------------------------------------------------------------

# 15. Brand architecture

Tramaj should remain the name of the language.

Host integrations should be described as integrations rather than
separate brands.

Examples:

``` text
Tramaj
Tramaj CLI
Tramaj Playground
Tramaj for Halogen
```

The core logo remains unchanged.

Avoid creating a different logo for every host or implementation.

------------------------------------------------------------------------

# 16. Technical identity

The brand should visually reinforce a few properties of the language.

### Small core

The identity should be simple enough to express with a few geometric
strokes.

### Composition

The weave is the central metaphor.

### Host independence

Avoid HTML, browser, React, Halogen, or other host-specific symbols in
the primary identity.

### Dynamic values, structured output

Lines and intersections are a better metaphor than literal markup.

### Static semantic vocabulary

The precise, geometric nature of the mark can subtly suggest that some
boundaries are intentionally well-defined even though the language
remains expressive.

------------------------------------------------------------------------

# 17. Example visual direction

The current preferred logo direction is:

``` text
     ─────────────
            │
   ─────────┤
            │
            │
            │
```

with the actual crossing rendered as an intentional over/under weave.

The preferred two-color treatment uses **Tramaj Ink** for the main
structural stroke and **Tramaj Coral** for the weaving stroke.

The wordmark sits alongside it in lowercase:

``` text
[ woven T ]  tramaj
```

The final artwork should be redrawn as a precise vector mark; the above
is only a conceptual representation.

------------------------------------------------------------------------

# 18. Brand principle

> **Tramaj should look like the language feels: small, structured,
> compositional, and more powerful than its surface suggests.**
